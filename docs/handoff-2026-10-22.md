## 已完成的工作

### 1. 云盘界面与真实挂载

- 桌面、开始菜单和任务栏可打开“云盘”，有独立窗口。
- 账号列表、文件列表、测试连接、添加和解除挂载均调用 Go API。
- 支持面包屑、返回上级/根目录、当前目录搜索、列表/网格、排序、收藏与最近使用。
- 收藏存在浏览器 localStorage，最近使用只保留当前窗口会话；旧演示账号不会自动导入真实后端。
- 按驱动配置：115 / 百度 Token，夸克 Cookie / 扫码，本地目录浏览器；授权、测试连接、保存挂载是分开的步骤。
- 本地文本/图片支持预览，本地普通文件与夸克支持下载及 Range。夸克通过后端代理，凭据不交给浏览器。

### 2. Go 后端与数据保护

- Gin 路由、健康检查、环境变量配置、日志与优雅关闭。
- 纯 Go SQLite 存账号和任务；账号长期凭据使用 AES-256-GCM 加密。
- `cloud.db` 与 `credentials.key` 必须配套保留。已有数据库缺少密钥时拒绝生成新密钥，避免掩盖凭据损坏。
- 本地访问由允许目录列表和 `os.Root` 限制，目录列表跳过符号链接；NAS 共享需先映射/挂载到后端设备。
- 当前未实现管理员登录，只允许本机回环 API；Vite 也限制非本机 `/api` 访问。不能直接改成局域网/公网部署而忽略鉴权。

### 3. 授权与夸克扫码修复

- 夸克扫码由后端请求二维码、维护会话和 Cookie；前端只接收短期会话 ID、二维码和状态。
- 修复过“手机夸克扫码提示登录已过期”：调整扫码 URL 参数、请求 ID 与桌面 UA，处理扫码平台状态码及过期提示。
- 用户随后确认已进入手机“确认登录”页面，之后真实挂载创建、目录读取成功。不要退回旧二维码参数实现。
- 115 / 百度自动获取 Token 需要配置可信兼容的 `CLOUD_OAUTH_URL`，这里只实现服务客户端，不内置第三方 OAuth 服务或应用密钥。
- Token 刷新轮换即时持久化；测试连接保留短期凭据引用，避免测试后保存时继续用已经轮换失效的 Token。

### 4. 文件浏览与缓存

- 115、百度、夸克目录协议已接入，汇总上游分页。
- 按账号 ID + parent ID 缓存，支持空目录、TTL=0、不使用缓存的主动刷新，以及 singleflight 合并同目录并发。
- 按账号串行远程请求，保护 Token 轮换；缓存有 128 目录 / 估算 32 MiB 软预算。
- 远程目录须从挂载根目录逐级发现，不能任意传外部目录 ID。
- 前端每次追加显示 100 项，但不是上游首屏增量分页或真正虚拟滚动。搜索仅筛选当前目录，不递归。

### 5. Windows 文件操作

- 文件和空白处都有右键菜单。
- 拖拽框选、边缘自动滚动，Ctrl 多选、Shift 连选，选择数量显示；剪切项变淡。
- Ctrl+A/C/X/V、F2 重命名、Delete 移入回收站、Ctrl+Shift+N 新建目录；补了原生复制/剪切/粘贴事件兼容和目录切换后的键盘焦点恢复。
- **写操作目前支持夸克、本地 NAS**：新建目录、重命名、批量复制/移动/移入回收站；每批最多 100 项。
- 同名拒绝覆盖；同挂载复制/粘贴已接入，跨挂载剪贴板粘贴暂不支持，应使用“下载到本地”功能。
- 夸克复制轮询异步任务直到完成，删除使用网盘回收站。
- 本地删除移动到挂载根目录 `.cloud-trash`，不永久删除；可从系统文件管理器恢复，应用内尚无恢复面板。
- 写操作清除目录内容缓存，同时保留已发现的目录边界。

### 6. 后台下载到本地与任务列表（最后完成的功能）

- 入口：选中文件/文件夹 → 右键或工具栏“下载到本地” → 选择已挂载 NAS、保存目录、同名策略。
- **来源：夸克或本地 NAS；目标：本地 NAS/硬盘。** 目标是运行 Go 后端的设备可访问的目录，不是浏览器所在电脑的任意下载目录。
- 递归下载并保留目录结构、空目录；拒绝复制到源目录自身/子目录，也检查不同挂载对应同一真实目录的情况。
- 同名策略：跳过或自动重命名。并发任务在文件最终发布时再次判断同名，避免相互覆盖。
- 最多并行 2 个任务；SQLite 持久化状态、输入和已完成文件记录；关闭前端窗口/浏览器不影响后端任务。
- 任务列表：全部 / 进行中 / 已结束，显示字节进度、文件数、当前文件、速度、预计剩余时间、失败原因。
- 支持暂停、继续、取消、重试、打开目标目录和移除结束任务记录；移除记录不删除下载文件，不删除源文件。
- 隐藏临时文件 `.cloud-part-<任务ID>` 写在目标卷，完整写入并检查大小后再发布；失败/暂停/取消清理当前临时文件。临时文件不展示在目录列表。
- 后端重启后未完成任务恢复为暂停，用户点击继续。已完成文件按源 ID/大小/修改时间和本地文件大小验证后保留，**当前文件从头重新下载，不是字节级断点续传**。
- 重启后按保存的源目录链重新验证远程目录，任务记录不保存 Token/Cookie。
- 限制：每次选择最多 100 项，单任务最多扫描 20000 项 / 128 层，最多保留 500 条任务记录；超限明确报错，不静默截断。

关键区别：

- LitePan 的夸克“离线下载”走内置下载器：先下载到运行设备临时目录，再上传到夸克，成功后清理临时文件；不是夸克云端直接接管链接。
- LitePan 普通跨盘传输递归扫描，以批次创建持久化 relay 上传任务，下载临时文件再上传目标。
- OpenList 同存储优先原生复制；跨存储创建任务，源 Link/SeekableStream 对接目标驱动 Put，缓存方式仍取决于流/驱动。
- 本项目目标为本地磁盘，可以直接落盘，不需要“再上传”。第三方源码只用于理解行为，未直接复制其实现。

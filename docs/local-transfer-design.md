# 下载到本地：实现对照

## LitePan

调研版本：`e0e29c0e4c7fb4bc172d9bb66cb0292911b6693b`。

- [普通跨盘传输](https://github.com/Ponphil/LitePan/blob/e0e29c0e4c7fb4bc172d9bb66cb0292911b6693b/internal/crosstransfer/plain.go)：递归枚举源文件，创建目标目录结构，以批次创建 relay 上传任务。普通传输不探测秒传指纹，先下载到服务端临时目录，再上传目标存储；扫描和入队可报告进度。
- [任务接入](https://github.com/Ponphil/LitePan/blob/e0e29c0e4c7fb4bc172d9bb66cb0292911b6693b/internal/crosstransfer/service.go)：任务标记为 cross_transfer/downloading，交给持久化上传管理器执行，不依赖浏览器连接。
- [任务面板](https://github.com/Ponphil/LitePan/blob/e0e29c0e4c7fb4bc172d9bb66cb0292911b6693b/web/src/components/upload/TaskPanel.vue)：批次聚合，区分下载/上传阶段，显示进度、速度、暂停、失败、取消和重试入口。

## OpenList

调研版本：`70ed5eedb8edeaee67260a5b83efa22a33749257`。

- [复制/移动](https://github.com/OpenListTeam/OpenList/blob/70ed5eedb8edeaee67260a5b83efa22a33749257/internal/fs/copy_move.go)：同存储优先使用驱动原生操作；跨存储或不支持原生操作时，创建 FileTransferTask。目录递归生成子任务，文件通过源 Link 和 SeekableStream 交给目标驱动 Put，不要求全部先缓存为完整临时文件；具体缓存/落盘仍取决于流和驱动。
- [任务接口](https://github.com/OpenListTeam/OpenList/blob/70ed5eedb8edeaee67260a5b83efa22a33749257/server/handles/task.go)：区分进行中与已结束，提供取消、重试、批量取消/重试、重试失败等操作。
- [任务元数据](https://github.com/OpenListTeam/OpenList/blob/70ed5eedb8edeaee67260a5b83efa22a33749257/internal/task/base.go)：总大小、起止时间、执行上下文和取消/重试状态。

这里只研究行为和公开调用关系，项目实现独立编写，不复制第三方实现。

## 本项目

目标限定为已挂载的本地 NAS/硬盘，直接由 Go 后端读取源流并写入目标，不执行其他网盘的上传过程。NAS 指运行后端的设备可访问的本地/映射目录；浏览器下载继续作为独立入口。

- 来源目前支持夸克与本地 NAS，目标只允许本地 NAS。文件和文件夹可多选，保留目录结构，包括空目录。
- 右键/工具栏“下载到本地”，选择目标挂载和文件夹，以及同名跳过或自动重命名。拒绝源目录自身/子目录，包括不同挂载指向的重叠路径。
- 后台队列最多并行 2 个任务，SQLite 持久化记录。关闭窗口/浏览器不影响执行，后端停止则停止；重启后恢复为暂停，由用户继续。
- 任务面板提供全部/进行中/已结束筛选，进度、大小、文件数、当前文件、速度、预计剩余时间、错误原因、暂停/继续、取消/重试、打开目标及移除记录。
- 在目标卷写入隐藏临时文件，完整写入并检查大小后发布；失败/暂停/取消清理当前临时文件，已完成文件保留。并发任务发布时重新判断同名策略。移除任务记录不删除落盘文件。
- 继续/重试重新扫描源目录并验证已完成文件的 ID、大小、修改时间及本地大小；已完成文件不重新下载。当前文件从头开始，不声称字节级断点续传，也不提供校验和真实性保证。
- 远程目录从根目录逐级验证，重启后根据保存的源目录链重新建立边界。凭据仅从账号加密存储读取，不写入任务 JSON，不返回前端。
- 单任务扫描上限 20000 项、128 层，最多保留 500 条任务记录。达到扫描上限时明确失败，要求分批，不静默截断。

## 验证

Go 测试覆盖目录递归、空目录、同名策略、源文件保留、任务持久化、重启恢复为暂停、夸克模拟下载的暂停/取消/重试、私密凭据不落入任务数据、未列出源拒绝、两个并发任务保留同名副本。

页面联调使用临时本地目录，批量下载两个文件，检查任务完成、“打开目标”定位及源/目标 SHA-256 一致。夸克真实账号的文件下载没有作为测试操作；其传输协议使用模拟测试。
